## OOP
=======
Object => Object is the Entitie of Real world
class => Class is the blueprint/structure for that object/entitie.

- OOP have Four Major Things
1. Encapsulation,  2. Extraction,  3. Inheritance,  4. Polymorphism

Encapsulation
=============
Encapsulation Means Wraping Up data(properties) and member functions(methods) in  a single unit called Class.

Bundling data and Methods That Operate on that data Together, While Controling how the internal data is accessed.

in simple way creating properties and methods in a class.
